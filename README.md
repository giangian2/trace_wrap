# Process Trace Wrapper

A straightforward Linux utility to analyze a process by recording its system calls and network traffic into local log files.

The script runs your target command under `strace` while running `tcpdump` in the background, filtering packets by your user ID to minimize system noise.

## Prerequisites

The script requires `strace` and `tcpdump`. Install them via your package manager:

```bash
sudo apt update && sudo apt install -y strace tcpdump
```

## Installation

1. Clone this repository:
   ```bash
   git clone <your-repository-url>
   cd <repository-folder>
   ```

2. Make the script executable:
   ```bash
   chmod +x trace-wrap.sh
   ```

## Usage

Run the script using `sudo` followed by the command you want to profile:

```bash
sudo ./trace-wrap.sh curl https://example.com
```

## Output Files

Upon termination, the script generates an output directory named `trace_output_[RANDOM_ID]/` containing:

* **`syscalls.log`**: A text log generated by `strace` containing every system call, arguments, and execution microsecond timestamps.
* **`traffic.pcap`**: A network capture file containing packets sent and received during the execution, openable in **Wireshark**.
